# Unitopia IT-Service – Website, Admin-Bereich und Mitarbeiter-App

- `index.html` – Webseite (Leistungen, Anfrage-Formular)
- `admin.html` – Admin-Bereich (Anfragen, Status, Notizen, Team einladen)
- `app.html` – Mitarbeiter-App fürs Handy (Aufträge, Notizen, Benachrichtigung), installierbar
- `impressum.html`, `datenschutz.html` – bitte die Platzhalter in [eckigen Klammern] ausfüllen
- `config.js` – hier kommen URL und anon/publishable Key von Supabase hinein
- `supabase/` – `schema.sql`, die 4 Edge Functions und der Schlüssel-Generator
- **Einrichtung Schritt für Schritt: `ANLEITUNG-SUPABASE.md`**
